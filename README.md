# Gold Coast Trip Guide

휴대폰에서 사용하는 **Brisbane ↔ Gold Coast 당일치기 여행 가이드**입니다.

## Live site

- 🇰🇷 한국어: https://kerorobbang.github.io/goldcoast-trip-guide/
- 🇬🇧 English: https://kerorobbang.github.io/goldcoast-trip-guide/en.html
- 🇹🇼 繁體中文（台灣）: https://kerorobbang.github.io/goldcoast-trip-guide/zh-tw.html

## 주요 기능

- OpenStreetMap 기반 실제 지도
- 휴대폰 GPS watchPosition 기반 이동 중 현재 위치 실시간 갱신
- 현재 위치에서 가장 가까운 주요 지점과 방향/거리 표시
- 다음 목적지까지 거리 및 250 m 이내 도착권역 표시
- 지도에서 현재 위치 자동 따라가기 ON/OFF
- **교통(파랑) / 관광(주황) 색상 분리**
- R772 / G:link L1 / 704 승·하차 및 환승 안내
- Burleigh Heads, Charis Seafoods, Surfers Paradise, SkyPoint, Rick Shores 장소 설명 및 할 일
- Google Maps 길찾기 / Translink 링크
- 한국어 / English / 繁體中文 3개 페이지 전환
